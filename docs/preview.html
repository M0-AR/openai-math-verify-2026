Abstract — the whole story in 30 seconds

On 6 October 2026, OpenAI released 722 AI-written mathematics manuscripts grouped into 372 result families, claiming progress on famous open problems: a fixed zero-free strip for the zeta function (Re > 7/8), a proof that the plane needs more than five colors, the exact irrationality exponent of π, the Unique Games Conjecture, a matrix-multiplication exponent of 9/4, and a special case of the Hodge conjecture — among hundreds more. About 63% come with machine-checkable Lean proofs; the rest are paper-only claims awaiting referees. This repository is an independent, from-scratch verification log: it recomputes every classical footprint locally (prime counts, colorings, π approximations), audits the public catalog live, and routes each headline claim to the correct checking lane — L1 (machine-checked + human-readable), L2 (machine-checked + expert review needed), L3 (paper only). One command reproduces everything: docker compose up. Nothing here is peer review; everything here is runnable evidence.

📊 Results — real recomputed numbers not screenshots of someone else's work

Primes: the curve vs reality

π(10⁶) = 78,498 recomputed by sieve; smooth curve ≈ 78,628 — off by ≈130. Observed error sits far below the scale a 7/8 strip would allow: numerically consistent (necessary, not sufficient).

π: lucky fractions run out

Scores: 22/7 → ≈3.4, 355/113 → ≈3.2, later convergents → ≈2. Exactly the footprint of “irrationality exponent = 2”. Flint–Hills spike at n=355: +24.6 — and that series sits outside the checked statement.

Moser spindle — why the plane needs ≥ 4 colors (drawn live)

7 points, 11 unit links. All 3⁷ = 2,187 colorings with 3 colors fail — checked by exhaustion. The second rhombus is rotated by θ = 2·arcsin(1/2√3) so the spindle edge is exactly unit length. Interactive proof that finite checks can settle small bounds — and why the “≠ 5 colors” claim needs heavier machinery.

🔍 How checking works — and where it stops

Lean is a programming language for mathematics: a small checker verifies every step, so a proof compiles or it doesn't. The Comparator then binds the solution to the exact stated question and allows only three standard axioms (propext, Classical.choice, Quot.sound). Your job shrinks to reading the question — but a correct proof can still prove the wrong thing if a definition drifted. Hence three lanes:

L1Machine-checked + human-readable

zeta Re>7/8 sentence; 9-line plane file; π exponent = 2. As solid as mathematics gets after an independent rebuild.

L2Machine-checked + expert review

Question files up to 17,000 lines — reading the question is itself research. Experts must certify the statement matches the conjecture.

L3Paper only — do not cite as verified

Hodge for CM varieties, Hilbert's 10th over ℚ, L = BPL, fast integer multiplication, Kakeya… months of refereeing ahead. The release itself warns some of these “could have issues”.

🌱 Beginner guide — read this and you are a professional

Let's work this out in a step-by-step way to be sure we have the right answer. No background assumed. Each step takes minutes and ends with something you ran yourself.

  1. Prime numbers are atoms. 2, 3, 5, 7, 11… every whole number is built by multiplying primes. Nobody has a formula for the next prime — but a smooth curve predicts how many there are. Step: run experiment 01 and see π(10⁶) = 78,498 appear on your screen.
  2. The Riemann guess. In 1859 Riemann tied primes to “zeros” living on a 1-unit-wide road. His guess: every zero sits exactly on the center line. The new claim clears everything right of 7/8 — the first fixed-width strip ever, if it holds. The million-dollar center line stays open.
  3. Painting the infinite sheet. Points 1 unit apart must differ in color. A triangle needs 3; the Moser spindle (above) needs 4; a honeycomb needs only 7. For 68 years the answer sat between 4 and 7; since 2018 between 5 and 7. The new claim kills 5. Step: run experiment 02.
  4. How close can fractions get to π? 22/7 misses by ~1/1000; 355/113 by ~3 parts in 10 million. Score each miss; ordinary numbers score 2 forever. The claim: π scores exactly 2 — the lucky fractions run out. Step: run experiment 03.
  5. Who checks the checkers? A proof can be correct yet prove the wrong thing. So read the question file (9 lines for the coloring claim!), not the 500,000-line proof. Step: run experiment 05 and read one statement aloud.
  6. Become the expert. Take the quiz below. Score 8/8 and you know more about this release than most interview candidates.

❓ Questions everyone asks

Did AI solve the Riemann hypothesis?

No. The claim is a weaker strip (Re > 7/8); the center line Re = 1/2 and the $1M prize are untouched.

Is any of it actually verified?

Parts are machine-checked (L1/L2) but await independent rebuilds; the paper-only parts (L3) await referees. This repo verifies the classical footprints and the catalog counts — and tells you exactly which lane each claim is in.

Why “372 out of 4,000” is not a success rate?

Outputs were grouped and filtered by significance; failed attempts were not disclosed. Read it as “372 kept”, not “372/4000 solved”.

Can I rerun the discovery?

No — the model, prompts, and per-result compute are undisclosed. You can rerun every check in this repo. That asymmetry is the point.

What remains for a publishable paper?

Rebuild one L1 Lean proof independently, extend the scope-exclusion table to all 185 statements, rerun the catalog audit weekly, and get one signed expert read of a short question file.
